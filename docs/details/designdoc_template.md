# プロダクト設計ドキュメント：Decision Path

---

## 1. プロダクト概要

本アプリは  
**人生の意思決定ログを基に、ロールモデルまでのキャリアパスを提示するアプリケーション**である。

ユーザーは

- 自分の人生の意思決定ログ
- 将来の目標
- 興味関心

を入力する。するとシステムは

- データベースに存在するロールモデル
- その人物の意思決定履歴
- 分岐したキャリア

を元に、**ユーザーが目標に到達するための行動指針を提示する。**

---

## 2. 解決したい課題

多くの人が次の問題を抱えている。

- 将来どういうキャリアを歩めばよいかわからない
- 成功している人がどのような意思決定をしてきたかわからない
- 今の選択が正しいか判断できない
- 同じ目標を持つ仲間がいない

つまり  
**「人生の意思決定に対する具体的な参考データが存在しない」**  
という問題がある。

---

## 3. ソリューション

人生の意思決定を**ログとして記録**し、さらに**他人の意思決定履歴と比較できる**ようにする。

これにより

- キャリアの選択肢
- 分岐
- 未来の可能性

を可視化する。

---

## 4. コア体験

### ① ロールモデルのキャリアを見る

ユーザーは**最終目標**を設定する。

例
- 東京科学大学に進学したい
- Google エンジニアになりたい
- 起業家になりたい

するとその目標に該当する人物がデータベースから検索され、その人物の意思決定・キャリア・分岐が時系列で表示される。

---

### ② 人生の分岐を確認する

システムには**代表的なターニングポイント**が定義されている。

```
高校卒業
↓
大学進学する？ → YES / NO
```

ユーザーが選択すると、データベースからその選択をした人のキャリアパターンが表示される。

```
大学進学 → 大学院 → 研究者
         → インターン → 起業
```

---

### ③ ロールモデルと会話する

ロールモデルについて AI が**擬似人格**を生成し、ユーザーが対話できる。

```
Q: 大学院行った方がいいですか？
A: 私の場合は大学院で研究テーマに出会えました。
   研究に興味があるならおすすめです。
```

---

## 5. 人生ログの設計

人生は**意思決定の連続**である。

```
高校卒業 → 大学進学 → インターン → 就職 → 転職
```

このログをデータとして保存し、可視化・比較に活用する。

---

## 6. ターニングポイントの定義

システム側で代表的な意思決定ポイントを定義する。

| タイミング | 選択肢 |
| --- | --- |
| 高校卒業後 | 大学進学する？ YES / NO |
| 大学進学した場合 | 大学院行く？ YES / NO |
| 就職時 | 大企業 / スタートアップ |

ユーザーは選択肢を選ぶことで人生ログを作成する。

---

## 7. 未来分岐の仕組み

ユーザーが選択した場合、データベースから同じ選択をした人のキャリアを取得し、複数の分岐パターンを提示する。

```
大学進学
 ├─ 大企業 → 管理職
 └─ スタートアップ → 起業
```

---

## 8. コミュニティ機能

同じ目標を持つユーザー同士でコミュニティを形成できる。

例
- 東京科学大学志望コミュニティ
- 起業志望コミュニティ

ユーザーは情報共有・相談・意見交換を行える。

---

## 9. MVP フロー

```
ユーザー登録
↓
目標設定
↓
ロールモデル検索
↓
キャリア履歴表示
↓
AI 相談
```

| --- | --- |

- ロールモデルがほしい

### 社会人
- 転職したい
- キャリアを大きく変えたい

---

## 13. このプロダクトの本質

このアプリは**人生の意思決定データベース**である。

```
意思決定 → 結果 → キャリア
```

人の選択とその結果を蓄積し、未来の意思決定に役立てる。
