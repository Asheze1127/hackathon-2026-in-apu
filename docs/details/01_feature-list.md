# 📋 機能一覧テンプレート：KCL Progress Board

## 0️⃣ 前提定義（最初に決める）


| 項目     | 内容                                                                     |
| ------ | ---------------------------------------------------------------------- |
| 対象ユーザー | 学生：就職や将来のキャリアについて悩んでいる / 社会人：転職したい                                     |
| 提供価値   | ネクストアクションを見せてくれる / 目標を現実的なものにする / ロールモデルを見つけ、その人との繋がりを作ってくれる。同じ目標の人と交流 |
| コア体験   | ・先人や他の人の意思決定の履歴をgithubの履歴みたいに確認してどのような道を歩んでいけば良いかを学ぶことができる。            |
| 成功指標   | ユーザーに次のアクションを示すことができる（10分で示せるとGood 30分ならOK）新たな繋がりを創出できる               |

# 1️⃣ 機能カテゴリ設計（自由定義）

## 【カテゴリA：進捗管理と可視化（Progress Board）】


| 優先度  | 機能名                    | 概要                 | ユーザー価値 |
| --- | --- | --- | --- |
| P0 | ログイン機能 | ログインすることで利用できる | ログイン機能を入れることでよりセキュアに行う | 
| P0 | 意思決定の記録 | これまでの意思決定の記録を行うことができる | ログを残して他人との比較を行う| 
| P0 | ロールモデルまでの分岐 | 自分が目指す人になるにはどのように進んでいけばいいかを見れる | ネクストアクションを明確にして見せることができる|
| P1 | 過去記録からの分岐 | 過去の選択から違う選択にした場合にどのような未来が待っているかを見ることができる | エンターテインメント。違う自分との交流|
| P1 | 擬似モデル（AI）| 擬似的な任意の対象者のパーソナル情報をもったAIと会話できる| 手軽にロールモデルとの擬似的な対話が可能になる|
| P3 | reactThreeFiber | これまでの意思決定を3Dで見ることができる | 意思決定に色分けなどを行うことでロールモデルとの違いやその人の性格を一目瞭然にする|

# 2️⃣ 優先順位の定義基準（共通ルール）


| 優先度   | 判断基準              |
| ----- | ----------------- |
| 🔴 P0 | これがないとプロダクトが成立しない |
| 🟡 P1 | 体験を大きく向上させる       |
| 🟢 P2 | 運用効率・継続率を改善する     |
| ⚪ P3  | 将来の拡張性・差別化        |


---

# 3️⃣ フェーズ整理テンプレート

```text
【Phase 0 - MVP】
🔴 P0のみ実装
- Slackでの進捗入力（/progress）と一覧ダッシュボード表示
- Slackでの質問入力（/question）とメンターへの転送基盤
- 最低限のDB（RDB）設計と構築

【Phase 1 - 体験向上】
🟡 P1追加
- 質問に対するAI（LLM）の一次回答と不足情報のヒアリング
- Slack上の議論をタスク化するためのアクション検知基盤
- SlackスレッドのAI要約とGitHubへの自動Issue起票機能

【Phase 2 - 安定化】
🟢 P2追加
- チームごとの進捗タイムライン履歴表示
- GitHub連携の各種管理機能

【Phase 3 - 拡張】
⚪ P3追加
- 蓄積データを活用した高度なダッシュボード分析機能
```
