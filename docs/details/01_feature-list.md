# 機能一覧：Decision Path

---

## 0. 前提定義


| 項目     | 内容                                          |
| ------ | ------------------------------------------- |
| 対象ユーザー | 学生（進路・キャリアに悩む）/ 社会人（転職・キャリア変更を検討中）          |
| 提供価値   | ネクストアクションの提示 / 目標を現実的に整理 / ロールモデルとの繋がり創出    |
| コア体験   | 先人の意思決定履歴を GitHub のコミット履歴のように辿り、自分の進むべき道を学ぶ |
| 成功指標   | ユーザーが 10 問以内に次の行動を決められる（初回） / 新たな人間関係が生まれる  |


---

## 1. 機能カテゴリ

### カテゴリ A：キャリア探索・ロールモデル


| 優先度   | 機能名                 | 概要                              | ユーザー価値              |
| ----- | ------------------- | ------------------------------- | ------------------- |
| 🔴 P0 | ユーザー登録 / ログイン       | アカウントを作成してサービスを利用開始する           | セキュアな個人データ管理        |
| 🔴 P0 | 目標設定                | 最終目標（大学・職業・ライフスタイル等）を設定する       | パーソナライズされた結果提示の基点   |
| 🔴 P0 | ロールモデル検索            | 目標に該当する人物をデータベースから検索・表示する       | 具体的なロールモデルの発見       |
| 🔴 P0 | キャリア履歴表示            | ロールモデルの意思決定履歴を時系列で表示する          | 先人の歩みを体系的に学べる       |
| 🔴 P0 | AI チャット（ロールモデル擬似人格） | ロールモデルの情報を基に AI が擬似人格を生成し、対話できる | 手軽にロールモデルと擬似的な対話が可能 |


### カテゴリ B：人生ログ・分岐可視化


| 優先度   | 機能名            | 概要                               | ユーザー価値                |
| ----- | -------------- | -------------------------------- | --------------------- |
| 🔴 P0 | 人生ログ記録         | 自分の意思決定履歴（学校・就職・転職など）を記録する       | 自己理解と他者との比較が可能になる     |
| 🟡 P1 | 未来分岐表示         | ターニングポイントでの選択肢と、各選択後のキャリア事例を表示する | ネクストアクションを具体的にイメージできる |
| 🟡 P1 | ロールモデルとの意思決定比較 | 自分のログとロールモデルの履歴を並べて差分を可視化する      | 自分の位置づけを客観視できる        |


### カテゴリ C：コミュニティ


| 優先度   | 機能名      | 概要                      | ユーザー価値             |
| ----- | -------- | ----------------------- | ------------------ |
| 🟢 P2 | 目標コミュニティ | 同じ目標を持つユーザー同士でグループを形成する | 同志と情報共有・相互サポートができる |
| 🟢 P2 | ディスカッション | コミュニティ内で意見交換・相談ができる     | キャリア不安の軽減・繋がりの創出   |


### カテゴリ D：拡張機能


| 優先度  | 機能名               | 概要                                    | ユーザー価値               |
| ---- | ----------------- | ------------------------------------- | -------------------- |
| ⚪ P3 | 人生シミュレーション        | 過去の選択を別の選択に変えた場合の未来パターンを提示する          | エンターテインメント兼自己洞察      |
| ⚪ P3 | 3D Decision Graph | 意思決定の分岐を 3D で可視化する（React Three Fiber） | ロールモデルとの違いを直感的に把握できる |


---

## 2. 優先度定義


| 優先度   | 判断基準               |
| ----- | ------------------ |
| 🔴 P0 | これがないとプロダクトが成立しない  |
| 🟡 P1 | 体験を大きく向上させる        |
| 🟢 P2 | 継続利用・コミュニティ形成を促進する |
| ⚪ P3  | 将来の拡張性・差別化         |


---

## 3. フェーズ計画

```
【Phase 0 - MVP】
🔴 P0 のみ実装
- ユーザー登録 / ログイン
- 目標設定
- ロールモデル検索・キャリア履歴表示
- AI チャット（ロールモデル擬似人格）
- 人生ログ記録

【Phase 1 - 体験向上】
🟡 P1 追加
- 未来分岐表示
- ロールモデルとの意思決定比較

【Phase 2 - コミュニティ】
🟢 P2 追加
- 目標コミュニティ
- ディスカッション機能

【Phase 3 - 拡張】
⚪ P3 追加
- 人生シミュレーション
- 3D Decision Graph
```
