# 機能一覧：Decision Path

---

## 0. 前提

| 項目 | 内容 |
| --- | --- |
| 対象ユーザー | 進路やキャリアに迷っている学生・社会人 |
| 提供価値 | 次の一手の具体化 / 先人の意思決定の学習 / 人とのつながりの獲得 |
| コア体験 | 自分の意思決定を木で可視化し、ロールモデルの軌跡と比較しながら進路を考える |

---

## 1. 実装済みの主要機能

### カテゴリ A: 認証 / オンボーディング

| 優先度 | 機能名 | 概要 |
| --- | --- | --- |
| 🔴 P0 | ログイン / 新規登録 | Supabase Auth による認証 |
| 🔴 P0 | 3ステップオンボーディング | 導入 → 必須2問 → 名前 / プロフィール入力 |
| 🔴 P0 | 初期ノード生成 | オンボーディング回答をルートノードとして保存 |

### カテゴリ B: 自分の木

| 優先度 | 機能名 | 概要 |
| --- | --- | --- |
| 🔴 P0 | 意思決定ツリー表示 | React Flow で自分の木を可視化 |
| 🔴 P0 | 未来 / 過去ノード追加 | ノード上部・下部から追加 |
| 🔴 P0 | ノード差し込み | 親子の間へノードを insert |
| 🔴 P0 | AI タグ付け | ノード保存時に `realTags` / `emotionalTags` を付与 |
| 🟡 P1 | 未来候補表示 | 他ユーザーの類似ノードから未来候補を最大5本・最大3手先まで表示 |

### カテゴリ C: ロールモデル

| 優先度 | 機能名 | 概要 |
| --- | --- | --- |
| 🔴 P0 | ロールモデル一覧 | 実ユーザーのプロフィールと木を一覧表示 |
| 🔴 P0 | ロールモデル詳細 | タイムライン / ツリー / プロフィール閲覧 |
| 🟡 P1 | ロールモデル保存 | `role_model_selections` に保存し、主ロールモデルを 1 件持てる |
| 🟡 P1 | ロールモデル比較 AI | 自分とロールモデルの木を比較し、次の一手を助言 |
| 🟡 P1 | ホーム比較カード | 主ロールモデルとの現在地比較をホームで表示 |
| 🟡 P1 | AI相談 | ロールモデルの公開情報と木をもとに擬似人格チャット |

### カテゴリ D: チャット / コミュニティ

| 優先度 | 機能名 | 概要 |
| --- | --- | --- |
| 🔴 P0 | 実ユーザー DM | プロフィールから 1対1 room を作成 / 再利用 |
| 🟡 P1 | コミュニティ room | `goal` があるユーザー向けの room 自動補完 |
| 🟡 P1 | Realtime 新着同期 | Supabase Realtime によるメッセージ反映 |
| 🟡 P1 | 入力中表示 | broadcast ベースの typing indicator |

### カテゴリ E: プロフィール

| 優先度 | 機能名 | 概要 |
| --- | --- | --- |
| 🔴 P0 | 自分のプロフィール閲覧 | 閲覧ページと編集ページを分離 |
| 🔴 P0 | プロフィール編集 | 名前、アイコン、職業、年齢、居住地を編集 |
| 🔴 P0 | アバターアップロード | Supabase Storage + Dropzone UI |

## 3. フェーズ整理

```text
Phase 0
- 認証
- オンボーディング
- 自分の木
- ロールモデル閲覧
- プロフィール編集

Phase 1
- 未来候補
- ロールモデル比較AI
- AI相談
- 実ユーザーDM / コミュニティ

Phase 2
- unread / 通知 / 添付ファイル

Phase 3
- 3D 表現
- より高度なシミュレーション
```
