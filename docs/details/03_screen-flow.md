# 画面遷移設計：Decision Path

---

## 0. 設計前提

| 項目 | 内容 |
| --- | --- |
| 対象ユーザー | 一般ユーザー（学生・社会人） |
| 対象チャネル | Web アプリのみ |
| デバイス | ブラウザが利用可能な端末 |
| 認証要否 | 全画面認証制（未ログインは `/auth/login` へリダイレクト） |
| 権限制御 | MVP は `USER` ロールのみ |
| MVP 範囲 | P0 画面（アカウント作成〜自分の木の閲覧・追加・分岐確認） |

---

## 1. 画面一覧

| ID | 画面名 | 役割 | 認証 | 優先度 |
| --- | --- | --- | --- | --- |
| S-01 | アカウント作成 / ログイン | 新規登録・ログイン | 不要 | P0 |
| S-02 | 最初のアンケート | 初回のみ表示。これまでの意思決定ログを一括入力する | 必須 | P0 |
| S-03 | ホーム画面・自分の木（ツリー表示） | 自分の意思決定ログをツリーで可視化する | 必須 | P0 |
| S-04 | 意思決定追加 | 新しいターニングポイント・選択を木に追加する | 必須 | P0 |
| S-05 | 選ばなかった道 | 別の選択肢を取った場合のキャリア事例を表示する | 必須 | P0 |
| S-06 | ロールモデル詳細 | ロールモデルのキャリア履歴表示 / AI チャット | 必須 | P1 |

---

## 2. 全体遷移図

```mermaid
flowchart LR
    S01[アカウント作成 / ログイン]
    S02[最初のアンケート\n今までの意思決定を入力]
    S03[ホーム画面]
    S04[自分の木を眺める]
    S05[自分の木に追加する]
    S06[自分が選択していない道を見る]
    S07[ロールモデル詳細 / AI チャット]

    S01 -->|初回ログイン| S02
    S01 -->|2回目以降| S03
    S02 --> S03
    S03 --> S04
    S04 --> S05
    S04 --> S06
    S03 -.->|P1| S07
```

---

## 3. 認証フロー

```mermaid
flowchart LR
    Access[アクセス] --> AuthCheck{ログイン済み?}
    AuthCheck -->|No| S01[アカウント作成 / ログイン]
    AuthCheck -->|Yes| OnboardCheck{初回ログイン?}
    OnboardCheck -->|Yes| S02[最初のアンケート]
    OnboardCheck -->|No| S03[ホーム画面]
    S01 --> OnboardCheck
    S02 --> S03
```

---

## 4. 画面別詳細

### S-01：アカウント作成 / ログイン

| 項目 | 内容 |
| --- | --- |
| URL | `/auth/login` |
| 主要操作 | メールアドレス + パスワードで登録 / ログイン |
| 遷移先 | 初回 → S-02 / 2 回目以降 → S-03 |

---

### S-02：最初のアンケート

| 項目 | 内容 |
| --- | --- |
| URL | `/onboarding` |
| 主要操作 | ターニングポイントと選択を複数入力して送信 |
| 遷移先 | S-03（ホーム画面） |
| 備考 | 初回ログイン時のみ表示。完了後は `users.onboarded = true` にする |

```mermaid
flowchart LR
    S02[最初のアンケート] --> Input[ターニングポイント・選択を入力]
    Input --> Submit[送信]
    Submit --> S03[ホーム画面]
```

---

### S-03：ホーム画面

| 項目 | 内容 |
| --- | --- |
| URL | `/` |
| 主要操作 | 「自分の木を見る」ボタン / ロールモデルを探す（P1） |
| 遷移先 | S-04（自分の木） / S-07（ロールモデル詳細・P1） |

---

### S-04：自分の木（ツリー表示）

| 項目 | 内容 |
| --- | --- |
| URL | `/tree` |
| 主要操作 | ツリーを閲覧 / ノードを選択して分岐を確認 / 追加ボタンで S-05 へ |
| 遷移先 | S-05（追加） / S-06（選ばなかった道） |

```mermaid
flowchart LR
    S04[自分の木を眺める]
    S04 -->|追加ボタン| S05[自分の木に追加する]
    S04 -->|ノード選択 → 別の道を見る| S06[選択していない道を見る]
```

---

### S-05：意思決定追加

| 項目 | 内容 |
| --- | --- |
| URL | `/tree/add` |
| 主要操作 | ターニングポイント・選択肢・選んだ選択を入力して保存 |
| 遷移先 | 保存後 → S-04（自分の木に戻る） |

---

### S-06：選ばなかった道

| 項目 | 内容 |
| --- | --- |
| URL | `/tree/branches?turning_point=xxx&choice=yyy` |
| 主要操作 | 別の選択をした人のキャリア事例を一覧で確認する |
| 遷移先 | S-04（自分の木に戻る） / S-07（ロールモデル詳細・P1） |

---

### S-07：ロールモデル詳細 / AI チャット（P1）

| 項目 | 内容 |
| --- | --- |
| URL | `/role-models/:id` |
| 主要操作 | キャリア履歴の閲覧 / AI チャットで質問する |
| 遷移先 | S-03（ホーム画面） |

---

## 5. エラーフロー

```mermaid
flowchart TD
    Action[ユーザー操作] --> API[API リクエスト]
    API -->|成功| RefreshUI[画面更新]
    API -->|401| RedirectLogin[ログイン画面へリダイレクト]
    API -->|403| ShowForbidden[権限エラー表示]
    API -->|404| ShowNotFound[データなし表示]
    API -->|5xx| ShowRetry[再試行を促すメッセージ表示]
```

---

## 6. 空状態 / 初回体験

```mermaid
flowchart TD
    S04[自分の木] --> HasLog{ログが存在する?}
    HasLog -->|No| EmptyTree[「まだログがありません。追加してみましょう」を表示]
    HasLog -->|Yes| ShowTree[ツリーを描画]

    S06[選ばなかった道] --> HasBranch{該当する事例が存在する?}
    HasBranch -->|No| EmptyBranch[「まだ事例が登録されていません」を表示]
    HasBranch -->|Yes| ShowBranch[キャリア事例を一覧表示]
```
